## 已确认指标

估算销售额是数量乘产品美元标价之和；估算毛利是数量乘美元标价与单位生产成本差额之和；估算毛利率使用汇总估算毛利除以汇总估算销售额。金额输出使用 USD，估算性质必须保留。

订单数按 order_number 去重；活跃客户数按所选范围内 sales.customer_key 去重；销量为 sales.quantity 合计。时间使用 sales.order_date，市场使用 customers.country。区间为左闭右开，未指定日期需补充，不能默认把历史样例当成当前业务数据。

## 独立对照结果

范围为 2019-01-01（包含）至 2020-01-01（不包含），客户国家 Germany。测试直接从原始 ZIP 读取 CSV，用 Python Decimal 独立计算，未复用 YAML 中的公式或生成 SQL；再与 MySQL 指标工具比较。

| 项目 | 原始 CSV 与 MySQL 核对结果 |
|---|---:|
| 估算销售额 USD | 1,874,921.45 |
| 估算毛利 USD | 1,100,621.76 |
| 估算毛利率 | 约 58.7023% |
| 订单数 | 892 |
| 活跃客户数 | 657 |
| 销量 | 6,928 |
| 匹配销售明细数 | 2,208 |

金额、计数、销量精确相等；比例按 MySQL Decimal 除法舍入允许绝对误差不超过 0.0000005。产品类别分组毛利率也分别与 CSV 核对。

## 测试

`.venv\Scripts\python.exe -X utf8 -m pytest -q`：118 passed，包含前两个阶段回归测试。

边界案例确认了订单去重、结束日期排除、加权毛利率、零销售额分母、空匹配、未知指标/维度/国家、重复 YAML 键、不安全 YAML 标签、循环依赖，以及缺少外键或唯一键时拒绝可能放大销售明细的关联。

实际 MySQL 查询 2026 年范围时返回 outside_data_coverage，不把样例中没有的年份解释成零销售。部分越界范围带 partial 标记。

## 当前限制与下一步

数据缺少实际成交价、历史价格/成本、折扣、税费、运费、取消与退货信息；不能由本字典推导实际确认收入、净利润或历史成本上涨原因。日期覆盖是记录的最小和最大日期，不构成数据每日完整性的证明。

当前工具根据明确的指标 ID、日期与筛选执行；还没有接入自然语言模型、前端或多步 Agent。下一步为 Phase 3，自然语言到业务意图及安全查询。
