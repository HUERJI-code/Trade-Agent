## 先打开页面

当前服务已启动，浏览器访问 `http://127.0.0.1:8000`。

电脑重启后，在 PowerShell 7 中运行：

```powershell
Set-Location 'D:\Codex\Trade Agent'
./scripts/local_model.ps1 start
./scripts/start_web.ps1
```

第一个命令启动本机 Ollama；第二个命令启动 FastAPI 并占用当前终端，按 Ctrl+C 结束。MySQL 也需要处于运行状态。若模型服务已经运行，第一步会提示端口已占用；先用 `./scripts/local_model.ps1 status` 核对即可，不要重复下载。

本次由助手启动的网页服务在后台运行，PID 记录在 `.runtime/web.pid`，日志在 `logs/web.stderr.log`。已有服务时直接打开页面，不要再占用同一端口。后台进程不等于开机自启。

在输入框填写“2019年德国销售额是多少？”，点击“开始分析”。应该显示 **估算销售额 1,874,921.45 美元**。点击示例问题只会填入输入框；点击提交才会执行查询。

如果输入“德国销售额是多少？”，页面会要求补时间。新会话版本可以在同一聊天中继续输入“2019年”；成功查询后可以追问“那法国呢？”或“订单数呢？”。新建会话不会继承其他聊天的条件。实现见 [LangChain 与 LangGraph 阅读指南](LangChain与LangGraph阅读指南.md)。

## 请求经过哪些文件

```text
frontend/index.html：浏览器加载外壳与本地 JS/CSS
  → frontend/src/main.jsx：React 读取输入框，POST /api/ask
  → api/main.py：校验请求来源、长度、字段和当前是否忙碌
  → agent/service.py：现有的问数服务
  → agent/local_model.py：调用本机 Qwen3-8B
  → agent/planner.py：检查模型给出的指标、日期、国家、分组
  → tools/business_tool.py：使用已确认的估算公式
  → tools/sql_tool.py：校验并执行只读 SQL
  → api/main.py：把真实结果作为 JSON 返回
  → main.jsx：显示答案、筛选条件、明细表、Plotly 图表
```

前端不连接 MySQL，也不持有数据库账号。金额由 SQL 计算；React 只处理显示格式。图表使用浮点数绘制，准确业务值以数据库返回值为准。表格金额直接对十进制字符串加千分位，避免先转换为浮点数而损失金额精度；鼠标悬停指标单元格可看原始值。毛利率展示为两位小数的百分比。

## 重要文件逐个读

### 1. `frontend/package.json` 与 `package-lock.json`

JSON 格式不能加注释，字段在此解释：

| 字段 | 含义 |
|---|---|
| name / version | 本项目前端包的名字和版本 |
| private | 防止误把教学项目发布到 npm |
| type: module | 允许构建脚本使用 import 语法 |
| scripts.build | 执行 npm run build 时运行 node build.mjs |
| dependencies.react | 用组件描述页面并管理输入、加载、结果等状态 |
| dependencies.react-dom | 把 React 组件绘制到浏览器 DOM |
| dependencies.plotly.js-basic-dist-min | 本地绘制折线图和柱形图 |
| devDependencies.esbuild | 将 JSX 和 CSS 编译、打包成浏览器资源 |

`package-lock.json` 是 npm 生成的依赖与完整性记录，不需要逐行手改。前端版本为 React/React DOM 19.2.8、Plotly basic 4.1.0、esbuild 0.28.2。本机 Node 为 20.17，选用兼容它的 esbuild 构建，不额外升级全局 Node。

### 2. `frontend/build.mjs` 和 `frontend/index.html`

`build.mjs` 先确定 frontend 的绝对路径，再创建 dist/assets，用 esbuild 编译 src/main.jsx，最后复制 index.html。所有 npm 依赖都打入本地 JS；页面不从 CDN 下载 React 或图表库。

HTML 中 `charset` 防止中文乱码，`viewport` 让手机按实际宽度排版，`link` 加载 CSS，`script type="module"` 加载 JS，`div id="root"` 是 React 的挂载点。页面中文标题用于浏览器标签。

构建产物在 `frontend/dist`。它们经过压缩，不适合逐行学习；应读 `frontend/src` 中的带注释源码。

### 3. `frontend/src/main.jsx`

按函数顺序阅读，每个函数解决一个问题：

| 名称 | 读的时候注意什么 |
|---|---|
| formatValue | 空值用破折号，不变成零；USD 增加千分位，比例转换百分比 |
| Chart | useRef 取得图表容器；useEffect 根据本次结果初始化 Plotly；月份折线、国家/类别柱形 |
| Chart 的清理函数 | 移除 ResizeObserver 和旧图表，避免查询多次后积累监听器 |
| Result | 展示答案和解析条件；有数据才画图/建表；无覆盖时显示说明而非伪造数值 |
| Result 的 details | 点击后查看实际执行 SQL 和模型解析计划，供核对与学习 |
| App | 管理 question、response、error、pending、health、checking 六组状态 |
| checkHealth | 页面加载或手动点击时检查模型和数据库，没有后台持续轮询 |
| submit | 阻止表单刷新、清除旧结果、POST JSON、处理成功/错误、恢复按钮 |
| createRoot | 将 App 组件挂载到 HTML 的 root 节点 |

常见语法：`useState` 返回“当前值、修改函数”；`onChange` 在输入变化时更新状态；`onSubmit` 处理提交；`条件 && <组件>` 表示条件成立才显示；`数组.map()` 把每条结果变为一行 JSX；`?.` 在对象不存在时返回 undefined；`??` 只为空值提供替代文本。`useEffect` 返回的函数负责清理副作用。

React 的 `{response.answer}` 按文本展示，不执行其中的 HTML。这里没有使用 `dangerouslySetInnerHTML`，也没有把模型原文拼进图表 HTML。输入与结果仅保存在当前组件内存；刷新页面会清空。

### 4. `frontend/src/styles.css`

`:root` 设置基础字体与颜色；`.workspace` 使用 CSS Grid 把查询区和说明区并排；`.main-column` 的 min-width:0 允许图表随容器收缩；`.table-scroll` 为多行、多列结果提供滚动；`@media` 在窄屏切换为上下排列；`prefers-reduced-motion` 尊重用户减少动画的设置。

CSS 不决定销售额算法，只影响布局、颜色、字号和反馈状态。图表会在 ResizeObserver 检测到容器宽度变化后调整大小。

### 5. `api/main.py`

Python 装饰器 `@app.get` / `@app.post` 将路径关联到函数。`AskRequest` 只允许一个 1–1000 字符的问题，禁止 sql 等多余字段。

`create_app()` 将分析服务、锁和路由组合成一个应用，测试时可传入模拟分析器。`check_request()` 检查同源、JSON 和实际请求体大小；它读取请求流后缓存 `_body` 供下游解析，这一行为已用当前锁定的 Starlette 版本验证。升级相关依赖时需要重跑接口测试。

`health()` 只检查模型安装/服务状态和数据库权限，不调用模型推理。缩短健康检查 HTTP 超时为 3 秒仅为了可用性提示，不改推理参数。`ask()` 取得非阻塞锁后在线程中运行同步分析器，结束后 finally 释放锁；忙碌时返回 429，错误返回 503，正常结果/澄清/不支持返回 200。

只有根页面和 `dist/assets` 会公开。`.env`、原始数据、模型权重与 Python 源码不作为网页静态文件。启动器只监听 127.0.0.1；该原型没有实现多人认证，不能直接改为公网服务。

### 6. `scripts/start_web.ps1`

使用项目 Python，检查 React 是否已构建，再启动 `uvicorn api.main:app`。host 固定 127.0.0.1，port 为 8000，workers 为 1。这里的单进程与分析锁配套；不能单改多进程就声称并发保护仍然全局有效。`--no-access-log` 避免默认访问日志记录请求路径。

### 7. `tests/test_api.py`

模拟测试验证：非法字段不调用分析器、过长内容被拒绝、跨站/错误 Host 被拒绝、金额字符串保留、异常不泄露内部错误、忙碌返回 429、异常后锁释放、静态路径不暴露项目文件。真实模型效果仍由 Phase 3 开发样例和本阶段浏览器联调验证。

## 修改代码后怎样运行

修改 React 或 CSS 后重新构建，再刷新页面：

```powershell
Set-Location 'D:\Codex\Trade Agent\frontend'
npm run build --cache ../.runtime/npm-cache
```

修改 Python 后需要重启 FastAPI；本阶段未开启自动热重载。首次在另一台机器恢复环境时，先在项目根目录创建 Python 虚拟环境，再安装锁定依赖；然后构建前端：

```powershell
Set-Location 'D:\Codex\Trade Agent'
./.venv/Scripts/python.exe -m pip install --cache-dir .runtime/pip-cache -r requirements-lock.txt
Set-Location frontend
npm ci --cache ../.runtime/npm-cache --no-fund --no-audit
npm run build --cache ../.runtime/npm-cache
```

`requirements.txt` 记录直接运行依赖，`requirements-dev.txt` 加测试依赖，`requirements-lock.txt` 固定本次已验证的完整 Python 环境。`.venv`、npm/pip 缓存、模型和运行目录都在项目 D 盘位置。
