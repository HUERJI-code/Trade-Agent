## 为什么训练输入必须包含查询结果

当前 `agent/local_model.py` 调用 Qwen3 生成查询计划，`agent/service.py` 的 `render_result()` 用固定文案生成最终回答。当前模型没有负责最终自然语言回答，因此只替换为微调权重不会改变这个模板。

后续的目标链路是：

```text
用户问题 → 原查询计划与校验 → 只读业务工具
                                 ↓
                      数值格式化、覆盖范围等事实
                                 ↓
                      回答风格模型 → 事实核验 → 展示
```

这里最后两个步骤尚未实施。计划解析仍然需要 JSON；回答风格数据用于新的回答阶段，不应直接混入原计划解析任务并期待两种输出自动兼容。后续可以为回答阶段使用独立适配器或独立模型标签。

训练目标是让模型学习“根据已有事实怎么说”，不是记住“德国2019年的销售额”。模型不能查询成功与否都输出同一个数字。样例 01 和 20 使用同一个问题，但上下文分别是成功和失败，因此回答不同。

## JSONL 每个字段是什么意思

| 字段 | 含义 |
|---|---|
| `messages` | 一条完整的监督学习候选对话 |
| `role: system` | 回答规则：自然完整的中文，按指标选择说明顺序，复制可信数值，保留估算及数据边界 |
| `role: user` | 问题与服务端上下文；内容是 JSON 文本，包含 `question` 和 `context` |
| `role: assistant` | 希望模型学会生成的目标回答 |
| `context.status` | 回答阶段使用的归一化状态，如成功、部分覆盖或失败 |
| `context.display` | 代码已经格式化的业务值，金额不用模型重新换算 |
| `context.period` / `country` | 已核验并中文化的时间与市场范围 |
| `context.ranking` / `winners` | 由代码完整比较后得到的排名事实 |
| `context.table_available` | 前端确实提供结果表时才为真，避免无依据地说“见下表” |

这些 `context` 字段是本次设计的回答阶段输入草案，不是当前 API 已经提供的接口。后续接入时需编写统一的转换层。不能让用户自由提交的 `context` 被当成数据库证据。

## 样例来源与可核验文件

`Data/answer_style/v0_review/review_manifest.json` 保存编号、类型、来源、原始业务结果、格式化上下文、目标回答和生成时间。JSONL 与它按相同顺序对应，训练输入中不混入审阅标签。

| 来源标记 | 数量 | 含义 |
|---|---:|---|
| `database` | 12 | 本次通过现有只读业务工具查询的教学数据结果 |
| `synthetic_edge_case` | 4 | 模拟无匹配、分母为零、并列、截断；不能用于业务报表 |
| `authored_flow_case` | 4 | 手工编写的补条件、不支持和失败情境；没有声称是当前完整链路的实测输出 |

真实样例包含六个指标、英国市场、国家最高最低、月度分组、部分覆盖及超出数据范围。原始结果排除了 SQL 与审计标识；不读取密码、姓名、生日等明细作为训练样例。

同一个国家和年份在模拟样例中可能对应不同数字或状态，这是刻意构造的条件变化。审阅文档明确标识来源，模型则需要遵循本次输入事实。

## 如何重新生成

生成脚本是 `scripts/build_answer_style_preview.py`。其中每个重要步骤都有中文注释：

- `fetch()`：调用现有 `run_metric()`，只读查询，并排除训练不需要的 SQL 和审计标识。
- `add()`：把问题、可信上下文和目标回答组合成消息列表。
- `main()`：生成真实查询样例、模拟边界和流程情境；验证基本结构并输出三个文件。
- `SYSTEM`：所有样例共享的风格与事实要求。
- `specs`：六个基础指标的候选回答文案。

在项目 PowerShell 中运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/build_answer_style_preview.py
```

运行需要 MySQL 可连接，不需要 Ollama，不启动训练。它会覆盖本次的三个生成文件；如要修改候选文案，修改生成脚本后再生成，或先另存审阅副本。
